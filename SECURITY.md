# Security Policy

## Supported Versions

The latest published version of the ZombieBuddy Windows Setup / Repair Helper is the version currently supported.

Older versions may no longer receive fixes or security-related updates.

## Reporting a Security Vulnerability

If you discover a potential security vulnerability in the ZombieBuddy Windows Setup / Repair Helper, please do not report sensitive security details in a public GitHub issue.

For ordinary bugs, installation problems, or feature requests, please use the repository's Bug Report or Feature Request forms instead.

For security-related issues, please use GitHub's private vulnerability reporting feature if it is available for this repository.

When reporting a security issue, please include as much relevant information as possible, such as:

- A clear description of the issue
- Steps required to reproduce it
- The affected version of the helper
- Your Windows version
- What effect the issue appears to have
- Any relevant logs or screenshots
- A suggested fix or workaround, if known

Please avoid including passwords, authentication tokens, API keys, personal information, or other sensitive data in reports.

## Responsible Disclosure

Please allow reasonable time for a reported security-related issue to be investigated and, when appropriate, fixed before publicly disclosing technical details that could affect other users.

Security reports will be reviewed as soon as reasonably possible.

## Scope

This policy applies to security-related issues that are directly caused by the ZombieBuddy Windows Setup / Repair Helper.

General Project Zomboid, Steam, Steam Workshop, mod, compatibility patch, or Windows-related issues should normally be reported through the appropriate project's own support channels unless the issue appears to be caused specifically by this helper.
